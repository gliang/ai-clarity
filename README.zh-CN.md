# AI Clarity

[English](README.md)

一个开源技能项目，帮助用户读懂 AI 的回答，并知道下一步该做什么。首个版本支持英文和中文。

**当前状态：实验性 alpha（`0.1.0-alpha.1`），尚未达到 v0.1 正式发布标准。** 仓库已包含核心技能、偏好工具、对比界面生成器和可卸载的 Hermes 安装器。安装需要主动选择；仅克隆仓库不会改变代理设置。已验证的行为及剩余事项见[验证报告](docs/VERIFICATION.md)。

## 提供的功能

- 通过技能和宿主的常驻指令，要求自动检查面向用户的回答；已有清晰表达时不改写。实际执行依赖模型遵循指令。
- 提供通用解释、学术研究、商业报告、产品设计和代码解释等轻量场景预设。
- 支持中英文回答、界面选项和反馈，允许用户指定输出语言。
- 按文档原有顺序展示完整的已接受回答。每个改写片段在原位置由独立卡片替代：先显示改写，再显示本地化的“AI Clarity 已修改”提示和默认折叠的“查看原文”。未改动文字原样保留在卡片外，只出现一次。没有改写就没有卡片或按钮。
- 提供针对所选片段的编辑和反馈选项，不要求输入斜杠命令。模型在语义核对后标明精确修改的句子或段落，工具验证映射并分配不透明标识。
- 精简、步骤、示例、有帮助和没有帮助均针对当前片段。不显示“场景”或“语言”控件；后台路由、偏好和旧操作词汇仍受支持。
- 经用户确认后，私下保存偏好，并在后续会话中应用相关偏好。支持查看、编辑、撤销、删除和导出。
- 保留原意、引用、代码、命令、警告和不确定性，不以牺牲准确性换取简短。

改写和原意检查由当前代理的模型完成。Python 工具负责偏好筛选、受保护文本检查、版本管理和界面生成，不生成解释。首先适配 Hermes Desktop；自动检查依赖模型遵循常驻指令，不能保证拦截每次输出。

宿主必须原样输出 `render.inline_markdown`，不能先输出完整改写再在末尾附加组件。工具负责按顺序组装，并让每条预览指令独占一个段落；多个片段对应多个文件。不支持本地预览时，改为原样输出完整的 `render.markdown` 后备内容，不能两者同时输出。编辑后，保留的片段文件路径不变，所有操作标识更新；不再使用的文件被删除，过期、重置及迁移也会清理。Desktop 中已挂载卡片的更新和移除尚未实测；解析源码证据见[验证报告](docs/VERIFICATION.md)。

## 本地试用

需要带 SQLite 的 Python 3.9+，运行于 macOS 或 Linux。已在 macOS 测试，尚未验证 Linux 实际运行；配套工具暂不支持 Windows。不需要第三方 Python 依赖或额外 API 密钥。

在仓库目录运行：

```sh
python3 -m unittest discover -s tests -v
python3 adapters/hermes/stage.py stage --home "$PWD/.local/hermes-demo"
```

暂存只复制技能到隔离的测试目录，不会激活。临时激活、工具命令及卸载步骤见[适配器说明](adapters/hermes/README.md)。手动试用时，让兼容的编程代理读取 [SKILL.md](skills/ai-clarity/SKILL.md)，并明确指定隔离的数据目录及读者、宿主标识。仅运行 Python 命令不会改写文本。

## 隐私与限制

- 经确认的个人偏好与共享技能分开保存。只修改当前回答，不会自动形成永久规则。
- 真实安装的数据默认保存在 `~/.local/share/ai-clarity`，按读者和宿主标识隔离。开发数据保存在 Git 忽略的 `.local/` 中。项目本身不加密数据。
- 交互对比最多保留 20 份回答快照，每份最多含五个历史版本。超过 24 小时后，在下次调用工具时清理；没有后台定时删除。反馈和撤销历史也有数量上限，见[数据控制说明](skills/ai-clarity/references/helper-workflow.md)。
- 当前宿主模型会收到处理所需的文本及相关偏好。本地存储不等于本地推理；配套工具不添加遥测或网络请求。
- 严格格式输出跳过存储和界面。受保护文本检查不能证明事实或原意完全保留，仍需模型另行核对。
- 旧调用若未提供片段映射，工具会采用保守的对齐段落。若无法安全映射片段，则保留已接受的回答，但不显示对比或按钮；绝不把整篇回答作为后备操作目标。存储从 schema 1 迁移到 schema 2：保留已批准偏好、撤销历史及标明旧格式的反馈；清除旧回答快照、待确认提案和组件，防止旧操作被悄悄转向新片段。详见[工具协议](skills/ai-clarity/references/helper-workflow.md)。
- 自动调用的可靠性因模型而异：一次全新真实会话测试跳过了规定的工具流程。Hermes 按钮点击及人类理解效果仍未验证。独立 HTML 文件中的按钮不会调用代理。
